I am Prashant Divate, an open-source learner and builder interested in Linux, Docker, Python, cloud platforms, and developer tooling.

This site is where I turn experiments into useful notes. I want each post to help another developer understand one command, one deployment, one bug, or one idea faster than I did the first time.

## Current Focus

- Publishing practical blogs from real experiments.
- Building small open-source utilities and examples.
- Learning cloud and DevOps workflows deeply enough to explain them clearly.
- Connecting with developers who enjoy sharing what they learn.

## Tools I Use

Docker, Python, Debian, Bash, AWS, Git, GitHub, Linux, VS Code, and Azure.
